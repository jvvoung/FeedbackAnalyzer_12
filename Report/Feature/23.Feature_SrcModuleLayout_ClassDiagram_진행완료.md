## 3. `src/cpp/` 모듈 구조 (To-Be)

### 3.1 디렉터리 트리

```
src/cpp/
├── app/
│   ├── main.cpp
│   ├── http/       RouteHandlers, FormParser, ServerConfig
│   ├── ui/         HtmlPageRenderer, AppMessages
│   ├── state/      AppState, FeedbackSession, Logger
│   └── usecase/    AnalyzeUseCase, FilterUseCase
├── csv/            CsvParser, CsvExporter, CsvConstants, FileHandler
├── feedback/       Feedback, TextAnalyzer, Filters, SentimentClassifier,
│                   FeedbackClassifier, Constants, KeywordRegistry, KeywordUtils, FilterConstants
└── httplib.h       (external, 루트 유지)
```

### 3.2 모듈 ↔ ECB 매핑

| 폴더 | 클래스 | ECB 역할 |
|------|--------|----------|
| **feedback/** | `Feedback`, `TextAnalyzer`, `Filters`, `SentimentClassifier`, `FeedbackClassifier`, `Constants`, `KeywordRegistry`, `KeywordUtils` | **Entity / Domain Service** |
| **csv/** | `CsvParser`, `CsvExporter`, `FileHandler`, `CsvConstants` | **Boundary** (I/O) |
| **app/http/** | `RouteHandlers`, `FormParser`, `ServerConfig` | **Boundary** (HTTP) |
| **app/ui/** | `HtmlPageRenderer`, `AppMessages` | **Boundary** (View) |
| **app/state/** | `AppState`, `FeedbackSession`, `Logger` | **Control** (상태) |
| **app/usecase/** | `AnalyzeUseCase`, `FilterUseCase` | **Control** (오케스트레이션) |
| **app/main.cpp** | bootstrap 18줄 | **Composition Root** |

### 3.3 재구성 이력 (2단계)

| 단계 | 변경 | 효과 |
|------|------|------|
| **1차** | flat → `app/`, `csv/`, `file/`, `feedback/` | 역할별 1차 분리 |
| **2차** | `file/` → `csv/` 통합; `app/` → `http·ui·state·usecase` | 과도한 flat `app/` 해소 |
