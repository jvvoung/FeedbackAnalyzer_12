### 3.3 Step 2 — GREEN (`FileHandler.cpp`)

```cpp
bool FileHandler::saveToCsv(const std::vector<Feedback>& data, const std::string& path) {
    std::ofstream ofs(path, std::ios::binary);
    if (!ofs.is_open()) {
        return false;
    }
    ofs << CsvExporter::exportFilteredFeedbacks(data);
    return true;
}
```

| 슬라이드 요건 | 구현 |
|--------------|------|
| `std::ofstream ofs(path)` | ✅ `std::ofstream ofs(path, std::ios::binary)` |
| `if (!ofs.is_open()) return false` | ✅ |
| UTF-8 BOM + `text\n` 헤더 | ✅ `CsvExporter` → `CsvConstants::kUtf8Bom`, `kTextColumnHeader` |
| 본문 `f.getText()` 저장 | ✅ `buildCsvBody` 내 `escapeCsvField(feedback.getText())` |
| 성공 시 `return true` | ✅ |

#### Windows 이슈 및 조치

| 현상 | 원인 | 조치 |
|------|------|------|
| FH-01~03 Fail — `\n` → `\r\n` | Windows 텍스트 모드 `ofstream` | `std::ios::binary` 플래그 추가 |
| PRD CSV 계약 | 바이트 단위 `\n` 고정 | `/download` 메모리 출력과 **동일 바이트** 보장 |

### 3.4 Step 3 — REFACTOR (`CsvExporter.cpp`)

**Before** — `exportFilteredFeedbacks()` 내부에 BOM·헤더·루프 인라인:

```cpp
std::string CsvExporter::exportFilteredFeedbacks(const std::vector<Feedback>& feedbacks) {
    std::ostringstream csv;
    csv << CsvConstants::kUtf8Bom;
    csv << CsvConstants::kTextColumnHeader;
    for (const auto& feedback : feedbacks) {
        csv << escapeCsvField(feedback.getText()) << "\n";
    }
    return csv.str();
}
```

**After** — anonymous namespace `buildCsvBody()` 추출:

```cpp
std::string buildCsvBody(const std::vector<Feedback>& feedbacks) { /* BOM + header + rows */ }

std::string CsvExporter::exportFilteredFeedbacks(const std::vector<Feedback>& feedbacks) {
    return buildCsvBody(feedbacks);
}
```

**DRY 관계 (1~2줄):**

- `buildCsvBody()`가 BOM·`text\n`·필드 이스케이프 본문 생성을 **단일 소스**로 담당한다.
- `FileHandler::saveToCsv()`는 `CsvExporter::exportFilteredFeedbacks()` 결과를 `ofstream`에 기록하므로, `/download`(HTTP)와 디스크 저장이 **동일 CSV 계약**을 공유한다.
