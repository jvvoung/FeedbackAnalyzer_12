## 3. 빌드·ctest 실행

### 3.1 실행 명령

```powershell
cmake -S c:\DEV\FeedbackAnalyzer_12 -B c:\DEV\FeedbackAnalyzer_12\build_cov -DENABLE_COVERAGE=ON
cmake --build c:\DEV\FeedbackAnalyzer_12\build_cov
ctest --test-dir c:\DEV\FeedbackAnalyzer_12\build_cov --output-on-failure
ctest --test-dir c:\DEV\FeedbackAnalyzer_12\build_cov -R GoldenMaster -V --output-on-failure

lcov --capture --directory build_cov --output-file coverage.info
lcov --remove coverage.info "*/tests/*" "*/googletest/*" "*/httplib.h" --output-file coverage.filtered.info
genhtml coverage.filtered.info --output-directory build_cov/coverage_html
lcov --list coverage.filtered.info
```

> **참고:** `CMakeLists.txt`에 `ENABLE_COVERAGE` 옵션은 **미구현** (`Manually-specified variables were not used`). `build_cov/CMakeCache`에 MinGW `--coverage -O0 -g` 플래그가 잔존하여 gcov 데이터 수집은 정상 동작하였다.
