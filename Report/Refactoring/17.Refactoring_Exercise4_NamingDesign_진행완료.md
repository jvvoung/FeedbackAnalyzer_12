## 3. 구현 상세

### 3.1 Part A-2 — `KeywordUtils` `std::any_of` 패턴

**Before** (`class KeywordUtils` + for-loop):

```cpp
class KeywordUtils {
public:
    static bool containsAny(...) {
        for (const auto& kw : keywords) { ... }
    }
};
```

**After** (`namespace KeywordUtils` + `inline` + `std::any_of`):

```cpp
namespace KeywordUtils {
inline bool containsAny(const std::string& text, const std::vector<std::string>& keywords) {
    return std::any_of(keywords.begin(), keywords.end(), [&text](const auto& kw) {
        return text.find(kw) != std::string::npos;
    });
}
}
```

|------|------|
| `TextAnalyzer.h` / `Filters.h` private `containsAny` | ✅ 없음 (R-L3 이후 `FeedbackClassifier` 경유) |

| `SentimentClassifier` / `FeedbackClassifier` 호출 | ✅ `KeywordUtils::containsAny` 유지 |
