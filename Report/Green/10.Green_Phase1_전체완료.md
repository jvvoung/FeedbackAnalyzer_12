## 5. 기술 변경 상세

### 5.1 H-2 / DEF-002 — CSV `text` 컬럼 (TC-B-04)

**As-Is:** `text` 컬럼 없을 때 `textIndex = 0` fallback → `"id,comment"` CSV에서 `"1"` 적재.

**To-Be:**

```cpp
// tests/support/CsvParser.cpp
const std::size_t textIndex = findTextColumnIndex(headerFields);
if (textIndex == static_cast<std::size_t>(-1)) {
    return result;  // 0건
}
```

`main.cpp` POST `/upload`도 헤더에서 `text` 인덱스 탐색 후, 없으면 데이터 행 skip(TC-B-04). TC-A-06에서 text 없음 시 **error alert** 추가.

### 5.2 H-3 / DEF-003 — 카테고리 `main` 키워드 (TC-B-05)

**As-Is:** `Filters.h`에서 `if (subEntry.first == "main") continue;` — TextAnalyzer `kw()`와 반대 동작.

**To-Be:** TextAnalyzer와 동일하게 `CATEGORY_KEYWORDS[kFilter]["main"]`만 매칭.

```cpp
if (catMap.count("main") && containsAny(txt, catMap.at("main"))) {
    finalFiltered.push_back(item);
}
```

### 5.3 M-7 — 감성 키워드 단일 소스 (TC-B-08)

| As-Is | To-Be |
|-------|-------|
| `Filters.cpp` stub `initFilterKeywords()` | **파일 삭제** |
| `main.cpp` `Filters::initFilterKeywords()` 호출 | **호출 제거** |
| `CMakeLists.txt` `Filters.cpp` 링크 | **제거** (Filters는 header-only) |

### 5.4 T-02 Happy Path (TC-A-01)

PRD 샘플 `"배송이 너무 늦어요. 화가 납니다."`가 `Constants::SENTIMENT_KEYWORDS["부정"]`에 매칭되도록 `u8"화가"`, `u8"늦"` 추가.

### 5.5 M-6 / AC-7 (TC-A-05/07)

- **M-6:** `fil_data` 비어 있을 때 GET `/download` → HTML warning `다운로드할 필터 결과가 없습니다.`
