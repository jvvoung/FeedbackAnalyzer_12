## 4. 기술 변경 상세

### 4.1 근본 원인 (DEF-001 / H-1)

| 레이어 | As-Is (Red) | 문제 |
|--------|-------------|------|
| `TextAnalyzer` | `Constants::SENTIMENT_KEYWORDS` — 긍정 → 부정 → **기본 중립** | 단일 소스 |
| `Filters` | `Filters::S_KEYWORDS` — 긍정 → 부정 → **중립 전용 키워드** | 이중 사전, 목록 상이 |
| 혼합 입력 예 | `"와우 정말 대단해요."` | TA=**긍정** (`Constants`에 `"와우"`), Filters=**중립** (`S_KEYWORDS` 긍정에 `"와우"` 없음) |

TC-B-02 canonical 단일 텍스트 `"그냥 그래요. 특별한 감정 없음."`은 Red에서도 통과 가능했으나, **키워드 소스·판정 규칙 자체가 불일치**하므로 프로덕션 수정이 필요했다.

### 4.2 프로덕션 수정 (As-Is → To-Be)

**`Filters.h` 감성 판정 블록 (핵심 diff):**

```cpp
// As-Is (Red)
if (containsAny(txt, S_KEYWORDS[u8"긍정"])) {
    currentSentiment = u8"긍정";
} else if (containsAny(txt, S_KEYWORDS[u8"부정"])) {
    currentSentiment = u8"부정";
} else if (containsAny(txt, S_KEYWORDS[u8"중립"])) {
    currentSentiment = u8"중립";
}

// To-Be (Green — TextAnalyzer.h:29-34와 동일)
if (containsAny(txt, Constants::SENTIMENT_KEYWORDS[u8"긍정"])) {
    currentSentiment = u8"긍정";
} else if (containsAny(txt, Constants::SENTIMENT_KEYWORDS[u8"부정"])) {
    currentSentiment = u8"부정";
}
// 긍/부 미매칭 → currentSentiment = u8"중립" (초기값 유지)
```

**`Filters.cpp`:**

| As-Is | To-Be |
|-------|-------|
| `S_KEYWORDS` static map + `initFilterKeywords()` 17줄 키워드 등록 | `void Filters::initFilterKeywords() {}` (빈 stub) |

> `main.cpp:235`의 `Filters::initFilterKeywords()` 호출은 **유지** — 시그니처·기동 흐름 변경 없음.
