## 2. 프로젝트 배경

### 2.1 프로젝트 성격

- **목적:** 자연어 고객 피드백 수집·분류·시각화 C++ 웹 앱을 리팩토링하며 클린 아키텍처·TDD 학습
- **기술 스택:** C++17, CMake 3.14+, cpp-httplib, MinGW/MSVC/Clang
- **실행:** `http://localhost:8080` (바인딩 `0.0.0.0:8080`)
- **특성:** 의도적 코드 스멜(God Function, 전역 상태, 중복 로직, Lava Flow) 포함 리팩토링 챌린지

### 2.2 초기 혼선 및 정정

초기 요청 시 Spring Boot 레거시 분석 템플릿이 제공되었으나, 실제 워크스페이스는 **C++ Feedback Analyzer** 프로젝트임을 확인하였다. 이후 동일 분석·문서화 프레임워크를 C++ 프로젝트에 맞게 적용하였다.

## 4. 코드베이스 분석 핵심 결과

> 상세: [`docs/analysis.md`](../docs/analysis.md)

### 4.1 아키텍처 현황 (As-Is)

| 계층 (목표) | 현재 구현 | 분리 여부 |
|-------------|-----------|-----------|
| Controller | `main.cpp` 라우트 람다 | ❌ HTML·파싱·비즈니스 혼재 |
| Service | `TextAnalyzer`, `Filters` | △ 부분 분리 |
| Repository/State | `Session`, `fil_data` | ❌ 전역 mutable |
| View | `renderPage()` in `main.cpp` | ❌ 130줄+ inline HTML |
| Domain | `Feedback` | △ 최소 모델 |
| Config | `Constants`, `Filters::S_KEYWORDS` | △ 분산·중복 |

### 4.2 HTTP 엔드포인트 (5개, 계약 유지 대상)

| Method | Path | 역할 |
|--------|------|------|
| GET | `/` | 대시보드 HTML |
| POST | `/analyze` | 텍스트 입력 + 집계 |
| POST | `/upload` | CSV 업로드 |
| POST | `/filter` | 감정·키워드 필터 |
| GET | `/download` | 필터 결과 CSV (UTF-8 BOM) |

### 4.3 P0 문제 (High)

| ID | 문제 | 근거 | 영향 |
|----|------|------|------|
| **H-1** | "중립" 필터: TextAnalyzer vs Filters 판정 기준 불일치 | `TextAnalyzer.h`, `Filters.cpp` | 기능 오류 |
| **H-2** | CSV `text` 컬럼 무시, `fields[0]`만 사용 | `main.cpp:299-306` | 기능 오류 |
| **H-3** | 키워드 필터가 `main` skip, 집계는 `main`만 사용 | `Filters.cpp:55-57`, `TextAnalyzer.h:52-54` | 기능 오류 |
| **H-4** | Google Test·CMake 테스트 타깃 0건 | `CMakeLists.txt` | 회귀 방지 불가 |

### 4.4 주요 Medium 이슈

- **M-1** God Function (`main.cpp` 372줄)
- **M-2** 전역 상태 분산 (`fil_data`, `globalSent/Kw`)
- **M-3** `containsAny` 중복
- **M-4** Logger UI 미연동
- **M-5** FileHandler Lava Flow
- **M-6** `/download` 대상 불명확 (필터 미실행 시 빈 CSV)
- **M-7** 감정 키워드 이중 관리 (`Constants` vs `Filters::S_KEYWORDS`)
