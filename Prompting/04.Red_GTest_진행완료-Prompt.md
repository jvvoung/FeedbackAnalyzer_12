    - 이동/복사 기본 동작
    - (권장) 긴 문자열 1건
    - UTF-8 한글 1건

    ### 5) KeywordUtils / containsAny (tests/support — Phase 2~3 대비)

    - UTF-8 한글 키워드 매칭
